# xrevive

A desktop launcher for original Xbox games recompiled with [Xrecomp](https://github.com/Teraflopping/Xrecomp), with online services from the Xbox Live revival at [xb.live](https://xb.live).

# Not ready yet. Expect release 12-13th October

## Planned

- Turn your own game discs into native PC games and keep them in one library.
- Sign in once with your xb.live account. Every game gets it.
- Download title updates and DLC.
- Play online the way the games were made to: matchmaking, friends, invites and leaderboards.
- Windows, macOS and Linux.

## You bring the games

xrevive does not ship any game. It builds each game from a disc you own.

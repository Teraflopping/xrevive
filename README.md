# xrevive

A desktop launcher for original Xbox games recompiled with [Xrecomp](https://github.com/Teraflopping/Xrecomp), with online services from the Xbox Live revival at [xb.live](https://xb.live).

## Download v0.1.4

[Download for Windows x64](https://github.com/Teraflopping/xrevive/releases/download/v0.1.4/xrevive_0.1.4_x64-setup.exe) · [All installers and release notes](https://github.com/Teraflopping/xrevive/releases/latest)

The hosted game executables currently support **Windows x64**. macOS and Linux launcher packages are also available, but do not run those Windows game builds natively.

## Features

- Stay signed in across restarts, and keep xrevive running in the tray when you close its window. Use **Quit xrevive** in the tray menu to exit.

- Add your own ISO or extracted game folder, then download its matching executable from Release or Beta.
- Browse available releases and upcoming games, with automatic game and launcher update checks.
- Sign in with xb.live and view friends, live lobbies, community events, and leaderboards.
- Manage installed games with play, local-file browsing, and uninstall actions.

## You bring the games

xrevive does not include game ISOs or assets. Supply your own game files. This version downloads published executables instead of compiling games locally; titles without an available executable can be extracted for later use.

Launcher updates are signed with the xrevive update key. Windows installers are not Authenticode-signed and macOS packages are not notarized, so first-install security prompts may appear.

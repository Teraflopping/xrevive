# xrevive

**English** · [Português](#português) · [中文](#中文)

A desktop launcher for original Xbox games recompiled with [Xrecomp](https://github.com/Teraflopping/Xrecomp), with online services from the Xbox Live revival at [xb.live](https://xb.live).

## Download v0.1.4

[Download for Windows x64](https://github.com/Teraflopping/xrevive/releases/download/v0.1.4/xrevive_0.1.4_x64-setup.exe) · [All installers and release notes](https://github.com/Teraflopping/xrevive/releases/latest)

The hosted game executables currently support **Windows x64**. macOS and Linux launcher packages are also available, but do not run those Windows game builds natively.

## Features

- Add your own ISO or extracted game folder, then recomp its matching executable from Release or Beta.
- Browse available releases and upcoming games, with automatic game and launcher update checks.
- Sign in with xb.live and view friends, live lobbies, community events, and leaderboards.
- Manage installed games with play, local-file browsing, and uninstall actions.

## You bring the games

xrevive does not include game ISOs or assets. Supply your own game files. This version downloads published executables instead of compiling games locally; titles without an available executable can be extracted for later use.

Launcher updates are signed with the xrevive update key. Windows installers are not Authenticode-signed and macOS packages are not notarized, so first-install security prompts may appear.

## Português

Um launcher para PC de jogos do Xbox original recompilados com o [Xrecomp](https://github.com/Teraflopping/Xrecomp), com serviços online do revival da Xbox Live em [xb.live](https://xb.live).

### Baixar v0.1.4

[Baixar para Windows x64](https://github.com/Teraflopping/xrevive/releases/download/v0.1.4/xrevive_0.1.4_x64-setup.exe) · [Todos os instaladores e notas de versão](https://github.com/Teraflopping/xrevive/releases/latest)

Os executáveis dos jogos hospedados atualmente suportam **Windows x64**. Também há pacotes do launcher para macOS e Linux, mas eles não rodam nativamente esses builds de jogos para Windows.

### Recursos

- Adicione sua própria ISO ou pasta do jogo extraída e faça o recomp do executável correspondente, da versão Release ou Beta.
- Veja os lançamentos disponíveis e os próximos jogos, com verificação automática de atualizações dos jogos e do launcher.
- Entre com o xb.live e veja amigos, lobbies ao vivo, eventos da comunidade e rankings.
- Gerencie os jogos instalados: jogar, abrir os arquivos locais e desinstalar.

### Você traz os jogos

O xrevive não inclui ISOs nem arquivos dos jogos. Use seus próprios arquivos. Esta versão baixa executáveis publicados em vez de compilar os jogos localmente; jogos sem executável disponível podem ser extraídos para uso futuro.

As atualizações do launcher são assinadas com a chave de atualização do xrevive. Os instaladores para Windows não têm assinatura Authenticode e os pacotes para macOS não são notarizados, então avisos de segurança podem aparecer na primeira instalação.

## 中文

一款用于运行经 [Xrecomp](https://github.com/Teraflopping/Xrecomp) 重编译的初代 Xbox 游戏的桌面启动器，并提供来自 Xbox Live 复兴项目 [xb.live](https://xb.live) 的在线服务。

### 下载 v0.1.4

[下载 Windows x64 版](https://github.com/Teraflopping/xrevive/releases/download/v0.1.4/xrevive_0.1.4_x64-setup.exe) · [所有安装包与更新说明](https://github.com/Teraflopping/xrevive/releases/latest)

目前托管的游戏可执行文件仅支持 **Windows x64**。启动器也提供 macOS 和 Linux 安装包，但无法原生运行这些 Windows 游戏版本。

### 功能

- 添加你自己的 ISO 或已解压的游戏文件夹，然后从 Release 或 Beta 获取对应的重编译可执行文件。
- 浏览已发布和即将推出的游戏，自动检查游戏与启动器更新。
- 使用 xb.live 登录，查看好友、在线大厅、社区活动和排行榜。
- 管理已安装的游戏：启动、浏览本地文件和卸载。

### 游戏需自备

xrevive 不包含任何游戏 ISO 或游戏资源，请使用你自己的游戏文件。此版本会下载已发布的可执行文件，而不是在本地编译游戏；暂无可执行文件的游戏可以先解压，以备日后使用。

启动器更新使用 xrevive 更新密钥签名。Windows 安装程序未进行 Authenticode 签名，macOS 安装包未经过公证，因此首次安装时可能会出现安全提示。

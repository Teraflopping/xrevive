# xrevive

**English** · [Português](#português) · [中文](#中文)

A desktop launcher for original Xbox games recompiled with [Xrecomp](https://github.com/Teraflopping/Xrecomp), with online services from the Xbox Live revival at [xb.live](https://xb.live).

## Download v0.1.10

[Download for Windows x64](https://github.com/Teraflopping/xrevive/releases/download/v0.1.10/xrevive_0.1.10_x64-setup.exe) · [All installers and release notes](https://github.com/Teraflopping/xrevive/releases/latest)

The hosted game executables currently support **Windows x64**. On Linux they can run through Wine or Proton (experimental). macOS packages can't play games yet.

## Features

- Add your own ISO or extracted game folder, then download its matching executable from Release or Beta.
- Browse available releases and upcoming games, with automatic game and launcher update checks.
- Sign in with xb.live (starting with Midnight Club 3 online), and view friends, live lobbies, community events, and leaderboards.
- Manage installed games with play, local-file browsing, uninstall, addon packs (DLC tab), and a Saves tab with backup, restore, import, and an MC3 save editor / PS2 save conversion.
- Add installed games to Steam (Settings or library), with cover art and Steam Input on Deck.
- System check for Windows 8.1+ and Direct3D 11, with optional Play anyway.
- Play always starts even if an XB Online save move is blocked; moves finish on a later launch, and the Saves screen is read-only for those moves.

## You bring the games

xrevive does not include game ISOs or assets. Supply your own game files. This version downloads published executables instead of compiling games locally; titles without an available executable can be extracted for later use.

The Windows launcher and installer are Authenticode-signed. Launcher updates are signed with the xrevive update key. macOS packages are not notarized, so first-install security prompts may appear on macOS.

## Português

Um launcher para PC de jogos do Xbox original recompilados com o [Xrecomp](https://github.com/Teraflopping/Xrecomp), com serviços online do revival da Xbox Live em [xb.live](https://xb.live).

### Baixar v0.1.10

[Baixar para Windows x64](https://github.com/Teraflopping/xrevive/releases/download/v0.1.10/xrevive_0.1.10_x64-setup.exe) · [Todos os instaladores e notas de versão](https://github.com/Teraflopping/xrevive/releases/latest)

Os executáveis dos jogos hospedados atualmente suportam **Windows x64**. No Linux eles podem rodar via Wine ou Proton (experimental). Os pacotes para macOS ainda não jogam.

### Recursos

- Adicione sua própria ISO ou pasta do jogo extraída e baixe o executável correspondente, da versão Release ou Beta.
- Veja os lançamentos disponíveis e os próximos jogos, com verificação automática de atualizações dos jogos e do launcher.
- Entre com o xb.live (começando pelo online de Midnight Club 3) e veja amigos, lobbies ao vivo, eventos da comunidade e rankings.
- Gerencie os jogos instalados: jogar, abrir os arquivos locais, desinstalar, pacotes de addons (aba DLC) e a aba Saves com backup, restauração, importação e editor de save / conversão de save de PS2 para MC3.
- Adicione jogos instalados ao Steam (Configurações ou biblioteca), com capas e Steam Input no Deck.
- Verificação de sistema para Windows 8.1+ e Direct3D 11, com opção de Jogar mesmo assim.
- O Play sempre inicia mesmo se a movimentação de saves do XB Online estiver bloqueada; a movimentação termina em um lançamento posterior, e a tela Saves é somente leitura para essas movimentações.

### Você traz os jogos

O xrevive não inclui ISOs nem arquivos dos jogos. Use seus próprios arquivos. Esta versão baixa executáveis publicados em vez de compilar os jogos localmente; jogos sem executável disponível podem ser extraídos para uso futuro.

O launcher e o instalador para Windows têm assinatura Authenticode. As atualizações do launcher são assinadas com a chave de atualização do xrevive. Os pacotes para macOS não são notarizados, então avisos de segurança podem aparecer na primeira instalação no macOS.

## 中文

一款用于运行经 [Xrecomp](https://github.com/Teraflopping/Xrecomp) 重编译的初代 Xbox 游戏的桌面启动器，并提供来自 Xbox Live 复兴项目 [xb.live](https://xb.live) 的在线服务。

### 下载 v0.1.10

[下载 Windows x64 版](https://github.com/Teraflopping/xrevive/releases/download/v0.1.10/xrevive_0.1.10_x64-setup.exe) · [所有安装包与更新说明](https://github.com/Teraflopping/xrevive/releases/latest)

目前托管的游戏可执行文件仅支持 **Windows x64**。在 Linux 上可通过 Wine 或 Proton 运行（实验性）。macOS 安装包尚无法游玩。

### 功能

- 添加你自己的 ISO 或已解压的游戏文件夹，然后从 Release 或 Beta 下载对应的可执行文件。
- 浏览已发布和即将推出的游戏，自动检查游戏与启动器更新。
- 使用 xb.live 登录（目前从 Midnight Club 3 在线开始），查看好友、在线大厅、社区活动和排行榜。
- 管理已安装的游戏：启动、浏览本地文件、卸载、附加包（DLC 页），以及带备份/还原/导入和 MC3 存档编辑器 / PS2 存档转换的 Saves 页。
- 将已安装游戏添加到 Steam（设置或库），支持封面与 Deck 上的 Steam Input。
- 系统检查：Windows 8.1+ 与 Direct3D 11，仍可选择继续游玩。
- 即使 XB Online 存档迁移被占用，Play 也会照常启动；迁移会在之后某次启动完成，Saves 页面对这些迁移为只读。

### 游戏需自备

xrevive 不包含任何游戏 ISO 或游戏资源，请使用你自己的游戏文件。此版本会下载已发布的可执行文件，而不是在本地编译游戏；暂无可执行文件的游戏可以先解压，以备日后使用。

Windows 启动器与安装程序已进行 Authenticode 签名。启动器更新使用 xrevive 更新密钥签名。macOS 安装包未经过公证，因此首次安装时可能会出现安全提示。

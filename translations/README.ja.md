# xrevive

### [**English**](../README.md) · [**Deutsch**](README.de.md) · [**Français**](README.fr.md) · [**Español**](README.es.md) · [**Italiano**](README.it.md) · [**Português (Brasil)**](README.pt-BR.md) · [**Русский**](README.ru.md) · [**العربية**](README.ar.md) · **日本語** · [**简体中文**](README.zh-CN.md)

[Xrecomp](https://github.com/Teraflopping/Xrecomp) で再コンパイルした初代 Xbox ゲーム用のデスクトップランチャーです。オンラインサービスは Xbox Live 復活プロジェクト [xb.live](https://xb.live) が提供します。

## ダウンロード

[Windows x64 版をダウンロード](https://github.com/Teraflopping/xrevive/releases/latest) · [Linux 版（AppImage）をダウンロード](https://github.com/Teraflopping/xrevive/releases/latest) · [すべてのインストーラーとリリースノート](https://github.com/Teraflopping/xrevive/releases/latest)

配信中のゲーム実行ファイルは現在 **Windows x64** に対応しています。Linux では Wine または Proton で実行できます（実験的）。macOS 版はまだゲームをプレイできません。

## 機能

- 手持ちの ISO または展開済みのゲームフォルダーを追加し、対応する実行ファイルをダウンロードします。Release ビルドがあればそれを使い、Beta や Alpha ビルドをインストールする前には確認します。対応ゲームのリージョンフリー版、メディアパッチ適用版、名前を変えたものや再署名したダンプも認識します。Beta や Alpha からインストールしたゲームは、お持ちのコピー向けの Release ビルドが出るとアップデートで Release に切り替わります。
- Release・Beta・Alpha のどのゲームもインストール前に閲覧できます：アクティビティ、アップデート、リーダーボード、実績、アドオン、リアルタイムのプレイヤー数とロビー数を表示し、ページ上から **INSTALL** できます。
- ゲームとランチャーのアップデートを自動確認。ゲームのアップデートは置き換えた古い実行ファイルを削除し、ゲームは近くのサーバーからダウンロードされ、接続が切れても続きから再開します。
- xb.live でサインイン（まずは Midnight Club 3 のオンラインから）し、ゲーマータグでフレンドを追加して、ライブ中のロビー、コミュニティイベント、XB Online のお知らせを表示できます。xb.live がダウンしていても、ゲームはオフラインで起動します。
- インストール済みゲームの管理：プレイ、ローカルファイルの参照、アンインストール、そして DLC/Addons タブ。各 MOD に On/Off スイッチと作者のクレジットがあります。**▶ PLAY** は有効な MOD を入れてゲームを起動し、アドオンはゲームのアップデート後も動作します。
- 各ゲームのページにあるセーブタブで、バックアップ、復元、インポート、好きなフォルダーへの **移動…**、PS2 セーブの変換（Xbox プロフィール不要）、Midnight Club 3 と NINJA GAIDEN Black のセーブエディターが使えます。
- 別の本体で署名されたセーブも xemu からインポートできます。NINJA GAIDEN Black など構造がわかっているセーブはこの PC 用に再署名され、未検証として表示されます。
- カスタムサウンドトラック：ミュージック画面でサウンドトラックを作成し、対応するすべてのゲームで流れる MP3、FLAC、Ogg、WAV、M4A、AAC の曲を追加できます（Midnight Club 3 は 1.0.7 アップデートから）。
- XB Online のタイトルアップデートと DLC はゲームを閉じている間に自動でインストールされ、各ゲームのアドオン一覧にタイトルアップデートがスイッチ付きで表示されます。オンラインプレイにはタイトルアップデートが必要です。未導入またはオフの場合、Play を押すとダウンロード（または再びオンに）するか、今回はオフラインで遊ぶかを確認します。
- XB Online のストアに DLC があるゲームは、DLC/Addons タブにダウンロードと削除付きで表示され、次回起動時にゲームが読み込みます。
- ゲームメニューからゲームごとの設定：フルスクリーン、解像度、VSync、アスペクト比、明るさ、コントラスト、彩度、アンチエイリアス、FPS 上限、DirectX 12・DirectX 11・Vulkan。Midnight Club 3 にはポルトガル語・ロシア語・アラビア語の翻訳アドオンを含む独自の言語リストもあります。
- ゲームごとのプレイ時間に加え、ゲームの EXE 名がアップデート後も変わらないので、NVIDIA コントロールパネルのプロファイルがそのまま適用されます。
- 設定で、ウィンドウを閉じたときに xrevive をトレイに残すか終了するかを選べます。タイトルアップデートで再起動するゲームもプレイ中のまま表示され、プレイ時間とオンラインセッションが引き継がれます。
- 設定 > ディスクインスペクターでディスクイメージのタイトル、タイトル ID、バージョン、リージョンを読み取り、バグ報告にそのまま貼り付けられるレポートをコピーできます。
- シェーダーキャッシュはゲームと一緒に保存されるので、シェーダーのコンパイルは初回起動時だけです。
- 何が起きたか、どう直せばよいかを説明するわかりやすいエラーメッセージ。「コントロールされたフォルダー アクセス」がインストールをブロックした場合は **Allow xrevive in Windows Security** ボタンが表示されます。
- 設定 > 言語 で 10 言語から選べます：英語、ドイツ語、フランス語、スペイン語、イタリア語、ポルトガル語（ブラジル）、ロシア語、アラビア語、日本語、簡体字中国語。アラビア語ではウィンドウ全体が右から左に表示されます。
- インストール済みゲームを Steam に追加（設定またはライブラリから）。カバーアートと Deck での Steam Input に対応します。
- ゲームを自分好みに：ゲームを右クリックして「管理」を開くと、自分で用意したバナーとアイコン（PNG または JPEG）を選べます。選ばない場合、ゲーム一覧には各ゲームの default.xbe にあるセーブアイコンが表示され、Steam への追加にも同じ画像が使われます。
- Windows 8.1 以降と Direct3D 11 のシステムチェック。それでもプレイすることもできます。
- Play を押すと、古い `XBL-Hosted` フォルダーにある XB Online のセーブが各ゲームの通常のセーブフォルダーにコピーされます。既存のセーブが置き換えられることはなく、何も削除されません。セーブを確認したら、`SaveData\XBL-Hosted` はご自身で削除できます。

## ゲームはご自身で

xrevive にはゲームの ISO やデータは含まれていません。ご自身のゲームファイルを使ってください。このバージョンはゲームをローカルでコンパイルする代わりに公開済みの実行ファイルをダウンロードします。実行ファイルがまだないゲームは、後で使えるよう展開しておけます。

Windows 版ランチャーとインストーラーは Authenticode 署名済みです。ランチャーのアップデートは xrevive のアップデート鍵で署名されています。macOS 版は公証（notarize）されていないため、macOS での初回インストール時にセキュリティの警告が表示されることがあります。
